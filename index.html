01 / SERVICES

Security and development, under one roof.

Whether you need a second pair of eyes on existing code or a new system built from scratch, you work directly with me from scoping to final report.

Secure code review & SAST

Static analysis and review of your codebase to find secrets, injection risks, weak access control and subtle compiler-level issues- All delivered as a clear, prioritised remediation report.

AI-built (Vibe-coded) app audit

Built an app with AI tools like Claude, Cursor or Lovable? I'll review it the way an attacker would, looking for exposed API keys, missing authentication, insecure database rules, and unvalidated input, and then give you a plain-English list of what to fix before you launch.

Application security consulting

Practical guidance on secure architecture, safe handling of personal and financial data, input validation and access control. All grounded in years of work in a regulated banking environment.

Custom software development

Web applications and backend systems in C#/.NET, Java, Python and C++, with SQL Server, MySQL, IBM DB2 or Oracle, built with secure coding practices from day one.

Automation & scripting

Python, Bash and PowerShell scripts for file management, data collection and processing, and routine admin tasks that take repetitive work off your plate.

Code modernisation

Upgrading legacy code to current standards (such as moving C++17 projects to C++20) and resolving the compiler errors and breakages that come with it.
